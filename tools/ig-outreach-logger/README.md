# IG Outreach Logger — PBPB

Chrome-расширение для фиксации рассылки дизайнерам в Instagram Direct.
**Сам не пишет сообщения.** Скрапит список переписок из открытой вкладки инбокса,
фильтрует по времени и пишет строки в Google-таблицу.

Этап 1 (MVP): приёмник — Google Sheets через Apps Script.
Этап 2 (позже): тот же POST, но на backend pbpb.club — меняется только URL в настройках.

---

## Что собирает (колонки таблицы)

| Записано | Отправлено | @логин | Имя | Ссылка на чат | Ответил | thread_id |
|----------|-----------|--------|-----|---------------|---------|-----------|

- **Отправлено** — вычисляется из относительного времени строки («25 мин.» → дата). Приблизительно.
- **@логин** — из списка входящих надёжно недоступен, обычно пусто (появится на этапе 2).
- **Ответил** — эвристика: если последнее сообщение «Вы…» → «нет», иначе «да». Не гарантия.
- **thread_id** — ключ дедупа (повторно строка не добавляется) и основа ссылки на чат.

## Установка расширения

1. Открой `chrome://extensions`, включи **Режим разработчика** (справа сверху).
2. **Загрузить распакованное** → выбери папку `ig-outreach-logger/`.
3. Иконка появится на панели. Закрепи её.

## Настройка Google-таблицы (один раз)

1. Создай новую Google-таблицу.
2. **Расширения → Apps Script**. Удали заготовку, вставь весь код из `apps-script.gs`.
3. **Развернуть → Создать развёртывание** → тип **Веб-приложение**:
   - *Запуск от имени*: я;
   - *У кого есть доступ*: **Все** (или «Все, у кого есть ссылка»).
4. Скопируй URL вида `https://script.google.com/macros/s/…/exec`.
   Проверка: открой его в браузере — должно показать `IG Outreach Logger webhook: ok`.
5. В расширении → **⚙ Настройки** → вставь URL, задай дефолтный фильтр → Сохранить.

---

## Как пользоваться

1. Сделай рассылку как обычно (вручную).
2. Открой `instagram.com/direct/inbox`, прокрути список так, чтобы нужные переписки
   загрузились (Instagram подгружает их по мере скролла — что не на экране, того в DOM нет).
3. Нажми иконку расширения → выбери фильтр («не старше N ч» или «с даты») →
   **Собрать из инбокса**.
4. Проверь превью-таблицу глазами → **Записать в таблицу**.
   Дубли (уже записанные) пропускаются автоматически.

## Отладка селекторов

Instagram даёт CSS-классам случайные имена, поэтому расширение цепляется за ссылки
`/direct/t/…` и за текст строки. Если разметка изменится и сбор вернёт **0**, popup
покажет «сырой текст, что видел в DOM» — по нему правится парсинг в `content.js`
(функции `scrapeInbox` и `parseRelTime`).

Живой Instagram нельзя протестировать без залогиненной сессии в браузере, поэтому
доводка селекторов делается на рабочей машине по этому сырому тексту.

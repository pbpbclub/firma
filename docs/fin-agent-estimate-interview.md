# Поручение фин-агенту: опрос Юры по заказам для актуализации смет

Дата: 25.07.2026. Составил инженер Firma.
Машинный список вопросов: **`docs/estimate-gaps.json`** (в репозитории firma) — веди опрос
по нему, не выдумывай вопросы сам.

---

## 1. Для оркестратора: хватает ли агенту функций

**Что уже умеет `firma.py`** (проверено по коду `/opt/fin-agent/tools/firma.py`):
`orders`, `order`, `estimate-queue`, `estimate-approve`, `cost-check`, `cost-fill`,
`rate-set`, `price-set`, `rates`, `stats`, `debtors`, `customers`.

**Чего не хватает для этой задачи** — записать ответы Юры. Нужны эти вызовы к API firma
(`http://127.0.0.1:8001`, JWT как у остальных команд). Либо добавить команды в `firma.py`,
либо ходить напрямую:

| Что делаем | Метод и путь | Тело |
|---|---|---|
| Свод пробелов по всем сметам | `GET /api/estimates/readiness` | — |
| Записать реальную себестоимость позиции | `PUT /api/estimates/items/{item_id}` | `{"cost_total": 90000}` |
| Записать цену строки (материал/работа) | `PUT /api/estimates/lines/{line_id}` | `{"unit_price": 3500}` |
| Выбрать актуальную смету из дублей | `POST /api/estimates/sets/{set_id}/keep-actual` | без тела |
| Добавить позицию в пустую смету | `POST /api/estimates/sets/{set_id}/items` | `{"title":"…","quantity":1,"markup":2.0}` |
| Добавить строку состава | `POST /api/estimates/items/{item_id}/lines` | `{"type":"material","title":"…","qty":1,"unit":"шт","unit_price":0}` |

**Важное изменение от 25.07 — прочитай, иначе будешь работать по-старому:**

1. **`cost-fill` больше не подставляет цены работ.** Раньше движок брал ставку из
   справочника; выяснилось, что Юре мастера называют цену каждый раз новую (сварка в его
   сметах: 1 700…30 000 ₽). Теперь цена работы **всегда спрашивается**, а в вопросе
   приходит подсказка из истории: «обычно 3 000–5 000 ₽; последние — 6 000 (05.07,
   Суздаль), 3 000, 4 500».
2. **`rate-set` для работ больше не нужен.** Ответ Юры пиши прямо в строку сметы
   (`PUT /api/estimates/lines/{id}`), а не в справочник ставок. Справочник ставок для работ
   мы намеренно не наполняем — разовая цена, попав туда, потом молча подставится в чужую
   смету (так появились мусорные «Сварка 30 000 ₽/шт» и «Покраска 40 000 ₽/шт»).
3. **`price-set` для материалов — по-прежнему да.** Материалы у Юры стабильные, цену вне
   прайсов (фанера, ткань, крепёж) запоминать полезно.
4. Себестоимость из `estimate-create` (`цена ÷ наценка`) firma теперь распознаёт как
   заглушку и спрашивает реальную цифру. Не считай такую позицию посчитанной.

## 2. Протокол опроса

**Главное правило: один вопрос за раз.** Юра ищет ответы руками в счетах и переписке —
не вываливай список из семнадцати пунктов, это его остановит.

1. Начни с короткой сводки: сколько заказов, сколько вопросов, сколько времени примерно.
2. Иди **по заказам в порядке из таблицы ниже** — сначала те, где вопросов больше.
3. По каждому вопросу дай контекст: заказ, позиция, цена клиенту, что сейчас стоит в
   себестоимости и почему это неверно. Если в `estimate-gaps.json` есть `history` —
   покажи вилку и последние цены, это ускорит ответ.
4. Получил ответ — **сразу запиши** (таблица вызовов выше) и подтверди: «записал: было
   66 100 → стало 90 000».
5. Юра говорит «не помню» / «надо посмотреть» — не дави, пометь вопрос как отложенный и
   иди дальше. В конце верни списком отложенное.
6. **Цифры не выдумывай и не переноси по аналогии.** Нет ответа — пусто.
7. После каждого заказа — итог в одну строку: «ORD-005: закрыто 5 из 6, осталось —
   цена материала».
8. В конце опроса: `firma.py cost-check ORD-XXX` по затронутым заказам — показать Юре, что
   вопросов не осталось, и предложить утвердить сметы (`estimate-approve`).

## 5. Особенности по брендам (чтобы не спрашивать лишнего)

- **Транзит** — состав не нужен: Юра называет свою долю, остальное уходит транзитом.
  Во всех трёх заказах доля ровно 13%. Спрашивай только, верна ли доля.
- **pbpb** — каталожные изделия, есть 36 рецептур. Если Юра называет себестоимость
  позиции, которая есть в каталоге, — это повод потом связать позицию с рецептурой
  (`catalog_item_id`), но в этом опросе не отвлекайся.
- **MeRA** — изделия уникальные. Материалы считаются по живым прайсам (нержавейка,
  409 позиций у Металлинвеста), работы Юра называет каждый раз заново.

## 6. Чего делать нельзя

- Не заполняй себестоимость «по аналогии» с похожим заказом.
- Не трогай утверждённые сметы (`approved`) — они заморожены, firma вернёт 409.
  Если нужно править — сначала спроси Юру, делать ли новую версию.
- Не пиши ставки работ в справочник (`rate-set`) — см. раздел 1, пункт 2.
- Не удаляй сметы. Лишние помечаются заменёнными через `keep-actual`.

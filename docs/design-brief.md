## 1. Обзор продукта

Firma связывает в одном месте всю операционку мастерской:

- **Заказы** → у заказа одна или несколько **смет** (версий расчёта).
- **Смета** состоит из **позиций** (изделий); позиция может иметь **строки калькулятора** (материалы / работы / доставка).
- При согласовании сметы строки превращаются в **обязательства** (кому и сколько платим — подрядчики/мастера).
- **Финансы**: ДДС (банк: Т-Банк + Сбер), Личные (ZenMoney), Фонды, Налоги (УСН 6%).
- **Бренды** (MeRA / pbpb / Транзит) и **Бизнес-единицы** (ИП Некрасов / Физлицо) — измерения учёта.
- Клиенты и Исполнители (мастера/подрядчики), Каталог изделий.

Пользователь один (админ), работает быстро и часто — **скорость и ясность заполнения важнее украшательств**.

## 2. Технологический стек и ограничения

- **Frontend:** React + TypeScript + Vite, `@tanstack/react-query`, `@phosphor-icons/react`.
- **Стили:** только **inline-стили** (Tailwind не используется, классы — лишь базовые в index.css).
- **Backend:** FastAPI + SQLite (не трогаем — только UI/UX-слой).
- **Нельзя:** border-radius, смена палитры/шрифта, сторонние UI-киты, смена стека.
- **Можно:** перекомпоновка, новые переиспользуемые компоненты, изменение порядка/группировки полей, единые модалки.

## 3. Дизайн-система (сохранить как есть)

Референс: минималистичный B2B (стиль Hue & Machine).

**Палитра**
```
#E8E4DA  beige — внешний фон (outer frame)
#FFFFFF  white — основной контейнер
#E8592A  orange accent — выделение, активные элементы, выбранные строки
#1A1A1A  text primary
#A89070  text secondary / метки
#6B6355  text muted
#EDEBE6  border / divider
#F2EFE9  тонкий divider строк
#FAF8F5  hover строки
#4A7C59  green — позитив (оплачено, поступления, +дельта)
#8B3A3A  red — негатив (долг, списания, перерасход)
```

**Лейаут**
- Внешний div: `background #E8E4DA`, `height 100vh`, `padding 36px 56px`, `box-sizing border-box`.
- Внутренний белый контейнер: `flex 1`, `box-shadow 0 2px 24px rgba(0,0,0,0.06)`.
- Сайдбар внутри белого контейнера: 60px (только иконки) ↔ 200px (раскрытый), гамбургер-тоггл.

**Правила вёрстки**
- **NO border-radius** — все углы строго прямые.
- Таблицы — без карточек-обёрток, прямо на белой поверхности; разделители `#F2EFE9`, hover `#FAF8F5`.
- Заголовок страницы: `fontSize 26, fontWeight 700, letterSpacing -0.03em`.
- Метки разделов: `fontSize 11, color #A89070, letterSpacing 0.06em`, CAPS.
- Тонкие прогресс-бары: `height 2px`, фон `#EDEBE6` + цветной div.
- Circular indicators: SVG, r=26, strokeWidth=3.5.
- **Фильтр-заголовок столбца** (эталонный паттерн, уже реализован в `components/TableFilters.tsx`): сам заголовок — кнопка с подчёркиванием (пунктир = фильтруемый, сплошной оранжевый = активный), клик → выпадашка вариантов / диапазон. Использовать этот паттерн как ориентир консистентности.

## 5. ГЛАВНЫЙ ФОКУС — единый калькулятор

Сейчас в системе **два разных калькулятора** расчёта изделия. Их надо свести к одному паттерну.

### A. Каталог — `Catalog.tsx → CalculatorModal` (~680px)
- Поля изделия: Название, Категория (select), Бренд (кнопки), Наценка — **в процентах (%)**, Примечание.
- Секции строк: **МАТЕРИАЛЫ / РАБОТЫ / ДОСТАВКА**, у каждой кнопка «+ Добавить …».
- Строка: `Наименование · Кол-во · Ед. · Цена · Итого · ×(удалить)`. Для материалов — автокомплит по справочнику материалов.
- Итог: Себестоимость → Наценка (%) → **Продажная цена**.

### B. Смета — `EstimateEditor.tsx → ItemModal`
- Шапка: название позиции + выбор **бренда** (кнопки MeRA/pbpb/Транзит).
- Строка: `тип-иконка · Наименование · Ед. · Кол-во · Цена · Итого · Исполнитель · ×`.
  - Для не-материалов: **Вид работ** (выпадающий список + «Добавить вид работ»), **Исполнитель** (секционированный select: по виду работ / все / добавить).
  - Ед. — выпадающий список (шт/м.п./м²/…+своя).
- Футер: «СЕБЕСТОИМОСТЬ 1 ШТ».

### Расхождения, которые надо устранить
| | Каталог (CalculatorModal) | Смета (ItemModal) |
|---|---|---|
| Порядок колонок | Наименование·Кол-во·Ед.·Цена·Итого | Наименование·Ед.·Кол-во·Цена·Итого |
| Наценка | в **%** (markup_pct) | **×множитель** (markup) |
| Исполнитель / вид работ | нет | есть |
| Группировка строк | секции Материалы/Работы/Доставка | плоский список, тип — иконкой |
| Футер-итог | «Продажная цена» | «Себестоимость 1 шт» |
| Ширина/шапка модалки | своя | своя |

**Задача:** один консистентный паттерн калькулятора — единые порядок колонок, представление наценки, группировка типов строк (материалы/работы/доставка), единый футер с разбивкой себестоимость → наценка → цена (и за штуку, и итого), единый блок назначения вида работ + исполнителя. Каталог и смета используют **один и тот же компонент строки/секций** (с опциональными полями исполнителя, когда это уместно).

## 6. Список UX-проблем для ревизии

- **P0 — два калькулятора** (см. §5): свести к одному паттерну.
- **P0 — представление наценки** разное (% vs ×): выбрать единое и понятное.
- **P1 — модалки разной ширины/структуры шапок** (440/480/520/680px, разные заголовки/кнопки): единый паттерн модального окна (шапка, тело-скролл, футер с действиями, «Удалить» слева, «Отмена/Сохранить» справа).
- **P1 — плотная таблица сметы (11 колонок)**: проверить читаемость на узких экранах, приоритезацию колонок, выравнивание чисел, единый стиль редактируемых ячеек.
- **P1 — affordance редактирования**: где инлайн-правка, где модалка — должно быть предсказуемо и единообразно (сейчас местами смешано).
- **P2 — кнопки-иконки**: единый размер/цвет/hover/подсказки по всему приложению.
- **P2 — пустые состояния** и состояния загрузки — единый стиль.
- **P2 — узкая/мобильная раскладка** — горизонтальный скролл таблиц, поведение сайдбара.

## 7. Цели и не-цели

**Цели:** единый калькулятор; консистентные модалки/таблицы/кнопки; ясность и скорость заполнения; понятная логика себестоимость→наценка→цена→дельта; сохранение визуального языка.

**Не-цели:** смена палитры/шрифта/радиусов; новый UI-кит/Tailwind; переписывание бэкенда и модели данных; новые крупные фичи.
